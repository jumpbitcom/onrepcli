# OnlineReports Client

OnlineReports is a Basel-based local news provider. This cross-platform native desktop client reads its public feed and article pages without embedding a browser.

## Features
Main feature is listed under (features.md)[features/features.md]

## Run

Prerequisite: .NET 10 SDK.

```sh
dotnet run --project src/OnlineReports.Client
```

## Test

```sh
dotnet test tests/OnlineReports.Client.Tests
```
